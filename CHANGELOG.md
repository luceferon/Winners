## [2.1.0] — 2026-11-25

### Краткое резюме (TL;DR)
В окно добавления ставки добавлена кнопка «Вставить ставку»: изображение берётся из буфера обмена, распознаётся офлайн (Windows OCR), и поля формы заполняются автоматически. Для экспресса распознаются события, прогнозы и коэффициенты (недостающий коэффициент события досчитывается из общего), для одиночной ставки — «Название события», «Прогноз», «Коэффициент» и «Сумма ставки». Счетчик тестов увеличен до 154.

### ⚠️ Breaking Changes (Критические изменения)
- Отсутствуют.

### 🚀 Новая функциональность (Added)
- **`app/services/ocr_service.py`**: сервис распознавания ставки со скриншота. Чтение изображения из буфера обмена (`PIL.ImageGrab`), офлайн-OCR через `Windows.Media.Ocr` (языки `ru`, затем `en-US`), предобработка (апскейл ×3 для мелких изображений) и парсер текста в поля `event_name`, `prediction`, `coefficient`, `stake`. Для экспресса собирает события экспресса парами строк (событие + прогноз) и привязывает коэффициент каждой ноги **по вертикальной координате** строки прогноза (коэффициент выровнен по правому краю на одной высоте с прогнозом своей ноги, а порядок строк в тексте OCR не гарантирован); общий коэффициент — число на высоте строки суммы. Единственный ненайденный коэффициент события досчитывается как «общий ÷ произведение остальных».
- **`app/schemas.py`**: схема `BetRecognitionOut` с распознанными полями, признаком вида `kind`, списком событий `legs` и исходным текстом `raw_text`.
- **`POST /api/bets/recognize`** (`app/api/bets.py`): принимает загруженный файл (`multipart/form-data`) либо, если файл не передан, читает изображение из буфера обмена; возвращает распознанные поля. При отсутствии изображения или недоступности OCR — `400` с понятным сообщением.
- **`web/index.html`**: в панели «Добавить ставку» добавлена кнопка «Вставить ставку».
- **`web/js/views/add.js`**: чтение изображения из буфера браузера (`navigator.clipboard.read`), вызов распознавания и автозаполнение полей формы с пересчётом; для экспресса переключается вид ставки и наполняются строки событий.
- **`web/js/api.js`**: метод `api.recognizeBet(blob)` и вспомогательная функция загрузки `upload()` на `FormData`.

### 🐛 Исправления ошибок (Fixed)
- Сумма с десятичной точкой распознавалась как целое число («Ставка 200.00» → `20000`): если у найденной суммы нет десятичного разделителя, изображение распознаётся повторно с бинаризацией, которая точку сохраняет. Из повторного прохода берётся только сумма — остальной текст обычный проход читает точнее.
- Коэффициенты экспресса привязывались к событиям по порядку строк в тексте, из-за чего раскладывались неверно (порядок строк у OCR не гарантирован). Теперь коэффициент каждой ноги определяется по вертикальной координате строки прогноза, а общий коэффициент — по высоте строки суммы.

### 🔄 Изменения и улучшения (Changed / Refactored)
- **`requirements.txt`**: добавлены `pillow`, `python-multipart` и четыре пакета `winrt-*` (условно для Windows).
- **`PROJECT.md`**: раздел §7 «Распознавание ставки со скриншота», эндпоинт в таблице REST API, обновлены версии и структура проекта, счетчик тестов 121 → 154, отмечена зависимость от Windows.
- **`web/js/views/add.js`**: автозаполнение для экспресса — вид ставки переключается на «экспресс», строки событий наполняются распознанными событиями, прогнозами и коэффициентами.
