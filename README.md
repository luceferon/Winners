# Winners — статистика спортивных ставок

Локальное однопользовательское приложение для учёта и анализа спортивных ставок.
Бэкенд — Python/FastAPI + SQLite, фронтенд — нативный JavaScript (ES-модули)
без сборки, графики — ECharts (локальный бандл, работает без интернета).

Ставки вводятся и рассчитываются **вручную**: пользователь сам добавляет ставки
и отмечает их результаты. Автоматического парсинга внешних данных и симуляции
матчей нет.

---

## Возможности

| Раздел | Что можно делать |
|---|---|
| **Общая статистика** | Сводка за период: KPI (количество, прибыль, проходимость, ROI, средний коэффициент), 9 графиков (включая просадку капитала), серии выигрышей/поражений, отчёт по месяцам, сравнение периодов, экспорт CSV. Панели можно перетаскивать — порядок сохраняется. |
| **История ставок** | Полный список (одиночные и экспрессы), фильтры, поиск, сортировка, пагинация, экспорт CSV, изменение результата, дублирование, массовые операции. Фильтры сохраняются между запусками. |
| **Новая ставка** | Ручной ввод одиночной ставки и экспресса с валидацией, автодополнением событий и калькулятором размера ставки (фиксированный % банкролла, Kelly). |
| **Баланс** | Учёт пополнений и выводов средств, текущий баланс с учётом прибыли и активных ставок, кривая баланса, Yield/ROI, цель и лимиты (stop-loss, максимальный размер ставки). |
| **Настройки** | Источники ставок (CRUD с сортировкой), банкролл и лимиты, уведомления (встроенные тосты и Telegram-бот с отправкой в личную переписку или группу), отображение (валюта, тема, период, компактные таблицы), демо-данные и сброс базы. |

## Быстрый старт

### Требования

- Python 3.11+ (разработка ведётся на 3.14)

### Установка

```bash
cd d:\project\Winners
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

### Запуск

```bash
python run.py
```

Приложение откроется в браузере по адресу **http://127.0.0.1:8000**.

На Windows запуск работает как приложение системного трея: консоль скрывается, а в
трее появляется значок **Winners** с меню:

- **Отобразить окно сервера** — показать окно «Winners — сервер» (двойной клик по значку);
- **Открыть в браузере** — открыть страницу сервера в браузере по умолчанию;
- **Выход** — остановить сервер и убрать значок.

Окно «Winners — сервер» показывает адрес и журнал сервера; **закрытие окна сворачивает
его в трей**, сервер при этом продолжает работать. Журнал можно выделять и копировать
(кнопка «Копировать», `Ctrl+C` или контекстное меню по правой кнопке).

Флаг `--reload` тоже работает вместе с треем: сервер с автоперезапуском идёт
отдельным процессом, а окно показывает его журнал (`data/winners-server.log`).

Доступные аргументы:

```bash
python run.py --host 0.0.0.0 --port 8080 --no-browser
python run.py --reload          # автоперезапуск при изменениях (значок трея остаётся)
python run.py --no-tray         # без значка в трее, обычный консольный запуск
```

База данных `data/winners.db` создаётся автоматически при первом запуске.

│   ├── css/styles.css        # Тема, сетки, панели, таблицы
│   └── js/

## Горячие клавиши

- `n` — новый раздел «Ставка»
- `/` — поиск в истории ставок
- `Esc` — закрыть модальное окно или боковое меню

Клавиши игнорируются, когда фокус находится в поле ввода.

## Принципы

- **Ручной ввод** — нет автоматического парсинга, нет симуляций.
- **Локальность** — всё работает на одной машине, SQLite, без интернета.
- **Прозрачность** — формулы расчёта баланса, прибыли, ROI и Kelly задокументированы в PROJECT.md.
